FIX 1 — Voice filter change.
Current code (lines around 88–89):
  const english  = raw.filter((v) => v.lang && v.lang.startsWith("en"));
  const filtered = english.length > 0 ? english : raw;
  setVoices(filtered);

Change to: show ALL voices. No filter. But default the initial selection to an English voice if one exists.

Specifically:
  setVoices(raw);                  // full list, no filter
  voicesRef.current = raw;

  const savedUri = localStorage.getItem("dexy-voice");
  const savedMatch = savedUri ? raw.find((v) => v.voiceURI === savedUri) : null;
  const englishMatch = raw.find((v) => v.lang && v.lang.startsWith("en"));
  const initial = savedMatch ?? englishMatch ?? raw[0] ?? null;

  setSelectedVoice(initial);
  voiceRef.current = initial;

So: saved voice wins. If no saved voice, prefer English. If no English voice, take the first one.

Change all three (changeRate, changePitch, changeVoice) so they only restart if ttsState === "speaking". When paused, just update the refs and the React state (so the UI control reflects the new value); don't call restartFromCurrent. The new rate/pitch/voice will take effect when the user resumes via toggle().

Example for changeRate:
  const changeRate = useCallback((newRate) => {
    setRate(newRate);
    rateRef.current = newRate;
    if (ttsState === "speaking") {
      restartFromCurrent(newRate, pitchRef.current, voiceRef.current);
    }
  }, [ttsState, restartFromCurrent]);

Same edit for changePitch and changeVoice — drop the "|| ttsState === 'paused'" branch.
