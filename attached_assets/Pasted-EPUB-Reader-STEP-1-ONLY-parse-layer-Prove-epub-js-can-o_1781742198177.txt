EPUB Reader — STEP 1 ONLY: parse layer. Prove epub.js can open a DRM-free
.epub inside the Capacitor WebView and extract text. NO UI, NO reader, NO
DRM detection yet. Console logs only. This is a tiny throwaway-style probe
to verify epub.js works on device before we build anything on top.

DO NOT build steps 2–6. Do not touch the reader, camera, or any existing
file. This step is fully isolated.

DEPENDENCY
- Add epubjs (the epub.js library).
- This is a pnpm project (Lesson 19) — the PC side will run pnpm install,
  not npm. Just add it to package.json correctly.

NEW FILES (isolated — create new, edit nothing that works)
- src/features/epub/epubParser.js
  Exports one async function, e.g. parseEpub(fileOrArrayBuffer), that:
    1. Opens the epub with epub.js.
    2. Reads metadata: title, author.
    3. Reads spine order (list of sections/chapters).
    4. Extracts the text of the FIRST spine section (clean text only).
    5. Returns { title, author, sectionCount, firstSectionText }.
  - No silent failures (Lesson 2): wrap in try/catch, log a clear error.
  - Keep ALL epub.js logic inside this one module (single-file discipline,
    same rule that kept Mega Stack clean).

TRIGGER (temporary, for testing only)
- Add a plain HTML file input: <input type="file" accept=".epub"> 
- On file select: read the file, call parseEpub, console.log the result.
- A simple hidden/dev-only spot is fine (e.g. a small input rendered behind
  a dev flag, or a /epub-test route). Make clear in a comment this trigger
  is TEMPORARY and gets removed before the real UI is built.
- Reset the input value AFTER reading the file, not before (Lesson 68 — the
  blob-release trap): await the file read fully, THEN clear input.value.
