══════════════════════════════════════════════════════════════
TASK 1 — Replace the text title with the logo wordmark
══════════════════════════════════════════════════════════════

- In App.jsx, replace the current <h1> "Dexy" / app-title element 
  with an <img> tag pointing to the wordmark PNG
- Use a proper alt attribute: alt="Dexy"
- Give it a class like .app-logo for styling
- REMOVE the decorative coloured underline from previous version 
  (the 3px lavender bar under the title) — the logo replaces it as 
  the visual anchor

══════════════════════════════════════════════════════════════
TASK 2 — Make it a hero element
══════════════════════════════════════════════════════════════

The logo should be the FIRST thing users see — big, confident, the 
clear identity of the page.

CSS for .app-logo:
- max-width: 280–320px on mobile (it should feel substantial)
- max-width: 360px on desktop
- height: auto (keep aspect ratio)
- display: block, centered horizontally (margin: 0 auto)
- margin-top: 2rem (some breathing room from top)
- margin-bottom: 2.5rem (space before the buttons)
- Add a SOFT drop shadow using CSS filter (not box-shadow, because 
  the image has transparency and we want the shadow to follow the 
  shape, not a rectangle):
    filter: drop-shadow(0 4px 16px rgba(120, 100, 180, 0.20));
  (Soft lavender-tinted shadow — matches the logo's own colour 
  family. This is the trick to make it feel like it sits on the page 
  with depth.)
