📋 DEXY — SESSION HANDOVER (12 May 2026)
Where the project is
Dexy is a phone-only accessibility app for dyslexic users: scan or paste text → it reads aloud with customisable display + voice. Built in React via Replit. Target: Play Store (Android first).
Phases complete: 1–7 plus Phase 8 Stage 1.
Current point: End of Phase 8 Stage 1. Ready to start Stage 2 (Capacitor install).

What works right now

Core flow: Scan (camera) → OCR → editable text → tap Read → speech with word highlighting and tap-to-resume
Backup paths: Upload from gallery, paste text
Display settings (all persisted): font size (14–36px), typeface (System/OpenDyslexic/Arial/Verdana/Georgia), background colour (7 pale presets), overlay opacity
Audio settings (all persisted): voice, speed, pitch
Auto-read toggle (default OFF, persisted)
OpenDyslexic bundled locally (no CDN dependency)
Production build works from any shell (npm run build → dist/public/)

8 localStorage keys: dexy-font-size, dexy-font-family, dexy-bg-colour, dexy-bg-opacity, dexy-voice, dexy-speed, dexy-pitch, dexy-auto-read

What's parked (known, do NOT fix)

Tesseract.js hallucinates on non-text photos. Phase 8 Stage 5 swaps for Google ML Kit.
Voice dropdown is decorative on Android web — Chrome ignores SpeechSynthesis voice selection. Phase 8 Stage 5 swaps for Capacitor TTS plugin.
Tap-to-resume is touch-only by design (desktop click triggers browser text selection). Not fixing — phone-only app.

Key technical patterns to remember (already in starter template as lessons 7–10)

Private repo from day 1 (going public-then-private doesn't un-publish)
Wrapper pattern for persisted settings — handle* functions wrapping hook methods, with localStorage writes
Platform may be the bug, not your code — test on desktop to rule out real bug before "fixing" working code
useRef + useEffect pattern for triggering actions after async state settles (used in auto-read)
