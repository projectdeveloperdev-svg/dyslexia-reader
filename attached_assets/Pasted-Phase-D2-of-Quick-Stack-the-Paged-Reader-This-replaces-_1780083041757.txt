PAGING / SWIPE (quote spec):
- Horizontal swipe between pages. ~200ms slide animation: current page slides off left, next slides in from right. Subtle, not flashy.
- Only one page mounted/visible at a time is fine; animate the transition.
- Page-indicator dots at the bottom: filled dot = current, hollow = others (e.g. ●○○○○ for 5 pages, current first).
- Dots are tappable to jump to that page (spec allows this for up to 5 pages).
- Show each page EXACTLY as captured. No stitching. No "continues →" hint between pages.

AUTO-ADVANCE TOGGLE (v2 spec — the key new behaviour):
- A toggle visible in the Paged Reader, ON by default. Label it clearly, e.g. "Auto-play next page".
- When ON: when TTS finishes reading the CURRENT page, automatically slide to the next page and start reading it. Play straight through the whole stack like a book.
  - At the LAST page: when TTS finishes, STOP SILENTLY. No audio cue. No loop back to page 1.
- When OFF: TTS reads the current page and stops silently at end of page. User swipes manually and taps play again. (This is the original v1 behaviour.)
- No audio cue at any page boundary in either mode.

INTERACTION RULES:
- If the user swipes manually (or taps a dot to jump) WHILE TTS is playing: stop the current page's audio immediately before transitioning. No audio bleed between pages. The new page starts idle (user taps play) UNLESS auto-advance just triggered the move (in which case the new page auto-plays).
- Distinguish the two move types: auto-advance move = auto-play the new page; manual move (swipe/dot) = land idle, even when auto-advance is ON.

  - Only call onPlaybackEnd on natural completion of speech, not on stop()/pause()/text change.
